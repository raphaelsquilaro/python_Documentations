# 📘 Python & CustomTkinter Docs

Um site simples e moderno criado com **HTML**, **CSS** e **JavaScript** para documentar conteúdos sobre **Python** e **CustomTkinter**.

---

## 🚀 Sobre o Projeto

Este projeto foi desenvolvido para servir como uma plataforma de documentação e aprendizado sobre:

- 🐍 Python
- 🎨 CustomTkinter
- 🧩 Interfaces gráicas modernas
- 📚 Exemplos de código
- 💡 Tutoriais e explicações

O objetivo é fornecer uma interface limpa, responsiva e fácil de navegar.

---

# 🛠️ Tecnologias Utilizadas

- HTML5
- CSS3
- JavaScript
- CustomTkinter (documentação)
- Python (conteúdo)
